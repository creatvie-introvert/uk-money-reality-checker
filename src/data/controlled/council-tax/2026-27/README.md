# UKMR-controlled council-tax extracts

These JSON files are reviewed selected-cell extracts from official MHCLG Table_9 ODS and Scottish Government Council Tax by band XLSX files. They are not original official documents or APIs. Embedded snapshot SHA-256 values describe the actual original files downloaded outside Git.

See [production council-tax documentation](../../../../../docs/data/production-council-tax.md) for source semantics, precision, authority scope, London handling and extraction reproduction. The UKMR raw workbook is not an input. Changes require source review, regeneration and validation; do not edit generated artifacts directly.
