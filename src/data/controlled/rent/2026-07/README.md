# UKMR-controlled ONS rent extract

`ons-pipr.json` contains 35 selected monetary cells for July 2026 from Table 1 of the ONS PIPR XLSX published 19 August 2026. It is a labelled UKMR-controlled extract, not an ONS-authored JSON file. The original checksum, URL, dates, row/cell references, literal values and geography labels remain attached. The raw official XLSX is metadata-only and is not committed.

See [production rent methodology](../../../../../docs/data/production-rent.md) for geographic applicability, missing-state handling, Edinburgh's unresolved source, reproduction commands and release gates.
